# When you need photos or 3D pictures

## Decide first

- Draw shapes, icons, pieces of screen, charts directly in code (SVG, CSS, canvas). They are easy to edit and stay sharp. The starter kit's cover (the window holding a prompt), check marks and window-shaped boxes are all done this way.
- Use pictures the brand kit already has (mascot, person cut-outs, objects) first.
- Make or source a photo or a new 3D object only when you really need one.

## Where to get photos and pictures

This bundle contains no image-making tool. Get a file any way that suits you, put it in the set folder's `images/`, and use it in `cards.html` as `<img src="images/filename">`.

- Use photos you took yourself or material you own (the safest).
- Make them with an image generation AI (check the service's terms for commercial use) and save them.
- What to put in an image generation request: file name, aspect ratio, scene description and tone (keep the tone the same for pictures in one set), no text, numbers, logos or watermarks, and for objects a transparent background with at least 10% margin around the edge.
- Open each generated picture yourself and check its size and whether it is transparent.

## Rules for using them

- Use a different picture on each slide. Don't reuse one photo by cropping it or just changing its colour.
- Don't pass off a generated photo as a real place or a real customer.
- Before using a picture that contains a person's face, a trademark or someone else's work, confirm you have the right to use it.
- Large PNGs can stay as they are in a set, but shrink them to WebP or JPEG when you put them in a brand kit.
